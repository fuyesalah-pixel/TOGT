# togt-mobile

Placeholder for the TOGT React Native (Expo) mobile app.

This app will mirror the Customer Dashboard web features, plus mobile-exclusive features:
- Azan alarm (location-based prayer times)
- Qibla locator (compass + GPS)
- Real-time GPS tracking (Umrah/tour groups)
- Push notifications

**Status:** Not yet scaffolded. Will be bootstrapped with `npx create-expo-app` in a later phase, once the web app and API are stable.
